# Da Cozinha à Consciência — Plataforma de Minijogos (UFPA | 6º Ano)

Plataforma web educativa em **React + TypeScript + Tailwind CSS** desenvolvida a partir da identidade visual original e do conteúdo dos slides da apresentação **"Da Cozinha à Consciência: Gestão de Resíduos Sólidos"** (Projeto de Extensão UFPA).

## Como executar no modo Desenvolvimento (React + TypeScript + Vite)

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor local:
   ```bash
   npm run dev
   ```
3. Acesse o link exibido no terminal (ex.: `http://localhost:5173`).

## Modo Sala de Aula Instantâneo (Sem precisar instalar Node.js)

Caso o computador da escola/sala de aula não possua o Node.js instalado, basta dar dois cliques no arquivo **`JOGAR_DIRETO_NO_NAVEGADOR.html`** incluído na raiz deste pacote `.zip`.
